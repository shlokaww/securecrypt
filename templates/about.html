About SecureCrypt

SecureCrypt encrypts text and files with AES-256-GCM. A password is never stored; Scrypt derives a 32-byte key using a fresh 32-byte salt (N=131072, r=8, p=1). Each operation uses a fresh 12-byte nonce.

File encryption uses one GCM authentication tag over the complete byte stream. This preserves ordering and integrity across chunks; incomplete or changed data fails verification.

Formats

Text payload: version, salt length and bytes, nonce length and bytes, ciphertext length and bytes, then the 16-byte authentication tag. The binary payload is Base64 encoded.

File container: version (1 byte), salt length (1) and salt, nonce length (1) and nonce, filename length (2-byte little-endian) and UTF-8 filename, ciphertext, then the 16-byte tag.
